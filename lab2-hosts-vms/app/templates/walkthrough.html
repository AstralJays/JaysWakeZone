Lab 2 · VM and Hosts

Walkthrough

Follow these steps in order. This app is intentionally vulnerable — the goal is Upwind detections, not “hacking for fun.”

  1. Connect the cloud account

    In Upwind, onboard this sandbox cloud so CSPM, agentless, DSPM, and activity logs are on.

  2. Get a shell on this VM

    AWS: aws ssm start-session (see terraform output lab2_ssm_command).
    Azure: SSH with the key from tfvars.
    GCP: gcloud compute ssh.

  3. Install the Upwind host sensor

    Paste the install command from the Upwind console / portal. Wait until this host shows up and has baselined L3 / L4 / L7 before generating attack traffic.

  4. Run Function-in-use modules

    Open All labs and hit the FiU cards (Pillow ×3, Brotli, PyYAML, tarfile). In Upwind, check Vuln Management → Function in use.

  5. Run classic AppSec + Webmin

    SQLi login, path traversal, and command injection from the lab list. Then open Webmin on port 10000 with admin / password for an exposed management-plane story.

  6. Investigate in Upwind

    Threats / Stories, runtime map, and FiU findings. Tie evidence back to this host and the modules you ran.

  7. Tear down

    terraform destroy in infrastructure/<cloud>/lab1-3 when finished.
